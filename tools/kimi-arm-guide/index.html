Product Overview

Kimi 产品矩阵与 ARM 支持概览

Kimi 官方提供多种形态的产品，在 ARM64 Linux 上的支持程度各不相同，选择适合目标平台的方案是第一步。

工具 / 产品 说明 ARM64 Linux 支持
Kimi Code CLI 官方命令行 AI Agent（终端编程助手） ✅ 官方支持
Kimi API OpenAI 兼容的 HTTP API ✅ 完全支持
MoonPalace（月宫） 官方 API 调试工具，Go 编写 ✅ 提供 Linux 二进制
VS Code 插件 Kimi Code IDE 扩展 ✅ 依赖 VS Code ARM64
Kimi 桌面版 官方 GUI 客户端 ❌ 无官方 Linux 版

核心结论：Kimi Code CLI 是纯 Python 实现（wheel 标签 py3-none-any），不依赖特定 CPU 架构，因此可在任何支持 Python 3.12+ 的 ARM64 Linux 平台上直接运行。

System Requirements

环境要求

明确 RK3576 及通用 ARM64 Linux 设备的软硬件门槛，避免安装过程中出现不兼容问题。

🖥
CPU
任意 ARM64 / AArch64 处理器均可。
推荐 RK3576（4×Cortex-A72 + 4×Cortex-A53）或更高性能平台。
🧠
内存
最低 512 MB RAM。
推荐 2 GB+，用于大型项目索引与复杂上下文处理。
💾
磁盘
最低 200 MB（Python + uv + Kimi CLI）。
推荐 1 GB+，含缓存、日志及模型文件。
🐧
操作系统
Linux 内核 4.x+，glibc 2.28+ 或 musl。
推荐 Ubuntu 22.04+ / Debian 12+ / Buildroot。
1
Python 版本
Kimi CLI 的硬性依赖

官方要求 Python ≥ 3.12，最佳兼容性版本为 Python 3.13。如果系统自带 Python 低于 3.12，请先升级。

bash
# 检查当前 Python 版本
python3 --version

# Ubuntu/Debian 安装 Python 3.13
sudo apt update
sudo apt install -y python3.13 python3.13-venv python3.13-pip

# 若系统包管理器无 3.13，可从源码编译或使用 uv 管理
2
网络环境
API 调用的前置条件

设备需能稳定访问 api.moonshot.ai（海外）或 api.moonshot.cn（国内）。如处于受限网络，需提前配置代理或检查防火墙策略。

bash
# 测试连通性
curl -I https://api.moonshot.cn/v1

# 如需代理
export HTTPS_PROXY=http://your-proxy:port
3
RK3576 特别提示
嵌入式 Linux 的额外注意点
  • 部分嵌入式发行版使用 musl libc 而非 glibc，uv 的 ARM64/musl 预编译版可用，但 uv python install 管理的 Python 解释器可能受限，建议使用系统自带 Python。
  • RK3576 内置 6 TOPS NPU，与 Kimi CLI 无直接关系，但可用于本地推理替代方案（见文末）。
  • 典型发行版：Buildroot、Ubuntu 22.04/24.04、Debian、openKylin、银河麒麟 V10。
Installation

安装方案

提供四种在 ARM64 Linux 上部署 Kimi 的方案，按推荐程度排序。

1
官方推荐：uv + kimi-cli
最简洁、官方维护的安装路径

uv 是由 Astral 开发的高性能 Python 包管理器，官方对 Linux aarch64 提供 Tier 2 支持（保证可构建，提供预编译二进制）。

  1. 安装 uv 包管理器
    运行官方安装脚本，自动识别 aarch64 架构并下载对应版本。
    bash
    curl -LsSf https://astral.sh/uv/install.sh | sh

# uv 将被安装到 ~/.local/bin/
# 脚本会自动识别 aarch64 并下载 uv-aarch64-unknown-linux-gnu
  2. 刷新环境变量
    使当前 shell 识别 uv 命令。
    bash
    source $HOME/.local/bin/env

# 或手动写入 ~/.bashrc
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
  3. 安装 Kimi CLI
    使用 Python 3.13 获得最佳兼容性。若系统无 3.13，可改用 --python 3.12 或 --python $(which python3)。
    bash
    uv tool install --python 3.13 kimi-cli

# 若使用系统自带 Python
uv tool install --python $(which python3) kimi-cli
  4. 验证安装
    bash
    kimi --version
kimi --help
  5. 启动并配置 API Key
    bash
    kimi
# 在交互界面中输入 /login 或 /setup 配置 API Key
2
系统 pip 安装
当 uv 遇到兼容性问题时使用

Kimi CLI 是纯 Python 包，不依赖架构，可直接通过 pip 安装。

bash
# 确保 Python >= 3.12
python3 --version

# 安装 kimi-cli
pip3 install kimi-cli

# 验证
kimi --version

# 升级
pip3 install -U kimi-cli

✅ 优势

  • 不依赖 uv，兼容所有 Python 环境
  • 适合 musl libc 嵌入式系统
  • 升级简单，pip 用户熟悉

⚠️ 注意

  • 可能污染系统 Python 环境
  • 不如 uv 的隔离性好
  • 依赖版本冲突风险稍高
3
Docker 容器化部署
环境隔离、可移植性最佳

适用于需要环境隔离、多版本共存或 musl libc 系统的场景。需预装 Docker（ARM64 版）。

dockerfile
FROM python:3.13-slim

WORKDIR /app

# 安装 uv
RUN apt-get update && apt-get install -y curl \
    && curl -LsSf https://astral.sh/uv/install.sh | sh \
    && apt-get clean
ENV PATH="/root/.local/bin:$PATH"

# 安装 Kimi CLI
RUN uv tool install kimi-cli

WORKDIR /workspace
CMD ["kimi"]
bash
# 构建镜像
docker build -t kimi-cli:latest .

# 运行容器（挂载配置与当前目录）
docker run -it --rm \
  -v $(pwd):/workspace \
  -v ~/.kimi:/root/.kimi \
  kimi-cli:latest
4
源码运行（开发者模式）
需要修改或调试时使用
bash
git clone https://github.com/MoonshotAI/kimi-cli.git
cd kimi-cli

# 使用 uv 安装依赖并运行
uv sync
uv run kimi

# 或直接以开发模式运行 Python
python3 -m kimi_cli
Command Reference

命令行操作速查

安装完成后，快速上手 Kimi CLI 的核心命令。

常用命令
# 启动交互式会话
kimi

# 直接执行单次提问
kimi "如何查看 Linux 内核版本？"

# 登录 / 配置 API Key
kimi /login
kimi /setup

# 查看版本与帮助
kimi --version
kimi --help

# 更新到最新版本（uv 安装）
uv tool upgrade kimi-cli

# 更新到最新版本（pip 安装）
pip3 install -U kimi-cli

# 卸载
uv tool uninstall kimi-cli
pip3 uninstall kimi-cli
Kimi API 调用示例
# 使用 curl 直接调用（无需安装 CLI）
curl https://api.moonshot.cn/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $MOONSHOT_API_KEY" \
  -d '{
    "model": "kimi-k2.6",
    "messages": [{"role": "user", "content": "你好"}]
  }'

# Python 示例
from openai import OpenAI

client = OpenAI(
    api_key="your-moonshot-api-key",
    base_url="https://api.moonshot.cn/v1"
)

completion = client.chat.completions.create(
    model="kimi-k2.6",
    messages=[{"role": "user", "content": "你好"}]
)
print(completion.choices[0].message.content)
FAQ

常见问题与解决方案

汇总在 ARM64 Linux 设备上安装和使用 Kimi 时的典型问题。

uv 安装脚本下载了错误架构的二进制文件？

某些精简版嵌入式系统可能无法正确识别架构。可手动下载对应版本：

# glibc 系统
curl -LO https://github.com/astral-sh/uv/releases/latest/download/uv-aarch64-unknown-linux-gnu.tar.gz
tar -xzf uv-aarch64-unknown-linux-gnu.tar.gz -C ~/.local/bin

# musl 系统
curl -LO https://github.com/astral-sh/uv/releases/latest/download/uv-aarch64-unknown-linux-musl.tar.gz
tar -xzf uv-aarch64-unknown-linux-musl.tar.gz -C ~/.local/bin
uv python install 3.13 在 ARM64/musl 上失败？

uv 对 ARM musl 平台的 Python 预构建版本支持尚不完整。解决方案：使用系统包管理器安装 Python 3.12+，再指定系统 Python 安装 Kimi CLI：

uv tool install --python $(which python3) kimi-cli
安装后 kimi 命令找不到？

uv 和 pip 的 user install 默认将可执行文件放到 ~/.local/bin，该目录可能不在 PATH 中：

export PATH="$HOME/.local/bin:$PATH"
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
Kimi CLI 启动时报 double free or corruption？

该问题曾在 Termux / Proot 等受限容器环境中报告。建议：

  • 更新 Kimi CLI 到最新版本：uv tool upgrade kimi-cli
  • 避免在受限容器中处理超大上下文
  • 尝试使用系统原生 Python 而非容器内版本
Asahi Linux（16K 页大小）上显示异常？

内核页大小非标准 4K 时，某些终端渲染库可能出现兼容性问题。通常不影响 Kimi CLI 核心对话功能，可尝试更换终端模拟器（如 Alacritty、Kitty）或更新至最新版本。

ARM 设备上运行缓慢或卡顿？

Kimi CLI 本身计算量很小，运行缓慢通常是网络延迟或内存不足导致：

  • 检查网络连通性：ping api.moonshot.cn
  • 关闭不必要的后台服务释放内存
  • 对于 RK3576 等 2GB 内存设备，避免同时运行大型 IDE 和 Kimi CLI
Alternatives

替代方案

当 Kimi CLI 不适合当前场景时，可考虑以下替代路径。

🌐

Kimi API

最通用方式，任何支持 HTTP 的语言均可调用，无需安装 CLI。

🍒

Cherry Studio

开源多模型桌面客户端，支持 Linux aarch64，可配置 Kimi API。

🗨

LobeChat / Next-Web

部署 Web 客户端，通过浏览器访问，后端调用 Kimi API。

🧠

RKLLM 本地推理

利用 RK3576 的 6 TOPS NPU 运行量化模型，适用于无网络场景。

1
Kimi API 直接调用
无需任何安装，最轻量

如果设备资源极其有限或仅需脚本化调用，直接使用 HTTP API 是最佳选择。支持 Python、Node.js、Go、Shell 等任意语言。

python
from openai import OpenAI

client = OpenAI(
    api_key="your-moonshot-api-key",
    base_url="https://api.moonshot.cn/v1"
)

response = client.chat.completions.create(
    model="kimi-k2.6",
    messages=[{"role": "user", "content": "你好"}]
)
print(response.choices[0].message.content)
2
RKLLM 本地量化部署（RK3576 NPU）
离线、隐私、零网络依赖

适用于无公网或数据隐私敏感场景。RK3576 的 NPU 可加速推理，但只能运行小型量化模型（如 DeepSeek-R1 1.5B/7B、Qwen2.5 等），并非 Kimi 本身。

部署流程概览
# 1. 上位机（x86 Linux）安装 RKLLM-Toolkit
pip3 install rkllm_toolkit-1.1.4-cp38-cp38-linux_x86_64.whl

# 2. 转换 HuggingFace 模型为 RKLLM 格式
python3 export_rkllm.py

# 3. 交叉编译 RKLLM Runtime
./build-linux.sh

# 4. 目标板（RK3576）运行
./llm_demo ../DeepSeek-R1-Distill-Qwen-1.5B_W4A16G128_RK3576.rkllm 2048 4096
Summary

综合建议

针对 RK3576 等 ARM64 Linux 平台的快速决策指南。

  • 1

    首选方案：uv + Kimi CLI

    安装 uv（aarch64 预编译版），再通过 uv tool install kimi-cli 安装。官方支持，纯 Python，ARM64 完全兼容。

  • 2

    uv 遇阻时：系统 pip 安装

    使用系统自带 Python 3.12+，执行 pip3 install kimi-cli。简单直接，适合 musl 嵌入式系统。

  • 3

    需要 GUI：Web 客户端 + Kimi API

    部署 LobeChat 或 Next-Web Docker 容器，通过浏览器访问，后端接入 Kimi API。

  • 4

    离线场景：RKLLM + NPU

    利用 RK3576 的 6 TOPS NPU 运行本地量化小模型，作为 Kimi 云端服务的离线替代。
