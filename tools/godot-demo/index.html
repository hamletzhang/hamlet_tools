Design

设计思路

从验证引擎能力出发，选择经典品类作为技术试验田，在可控复杂度内覆盖 Godot 核心特性。

为什么选择飞机射击

经典竖版射击（Shoot 'em up）规则明确、反馈即时，非常适合验证 Godot 的 2D 物理、输入系统、碰撞检测与粒子特效。无需复杂寻路或状态机即可做出"好玩"的原型。

核心玩法循环

玩家移动 → 自动射击 → 消灭敌人 → 积累分数 → 抵御波次 → 升级难度。循环周期控制在 10–30 秒，确保每波都有明显的难度递进与视觉变化。

设计目标

① 验证 Godot 4.x 节点场景工作流；② 实践 GDScript 2.0 类型系统与信号模式；③ 建立可复用的敌人基类 + 数据驱动波次系统；④ 验证 AI 辅助生成游戏代码的可行性。

AI 辅助开发定位

本项目将 AI 定位为"结对编程伙伴"——由人定义架构与接口，AI 生成具体实现与重复样板。所有代码均经过人工审阅、测试与调参，确保符合 Godot 最佳实践。

Architecture

架构解析

场景树关系、信号通信流与碰撞分层设计——理解 Godot"节点即对象"的核心理念。

主场景 main.tscn 的节点树结构，体现 Godot "组合优于继承" 的设计理念：

为什么选择信号而非直接调用

Godot 的信号系统（Signal）实现了发布-订阅模式。敌人死亡时只需发射 enemy_died，无需知道谁会接收——可能是加分系统、震动系统、粒子系统或成就系统。新增消费者无需修改生产者代码。

使用 Godot 的物理 Layer / Mask 机制实现精确的碰撞分组，避免不必要的碰撞检测：

层级 (Layer) 位号 包含节点 检测掩码 (Mask)
Player 1 Player 的 HurtBox EnemyBullet (4) + EnemyBody (3)
PlayerBullet 2 玩家发射的子弹 EnemyBody (3)
EnemyBody 3 所有敌人的 HurtBox PlayerBullet (2) + Player (1)
EnemyBullet 4 敌人发射的子弹 Player (1)
WorldBoundary 5 屏幕边界（用于清理越界子弹） PlayerBullet (2) + EnemyBullet (4)

Layer 与 Mask 的区别

Layer 定义"我属于哪个组"，Mask 定义"我想检测哪些组"。两个 Area2D 发生交集的充要条件是：A 的 Mask 包含 B 的 Layer 且 B 的 Mask 包含 A 的 Layer。WorldBoundary 只设置 Mask 不设置 Layer，因此它不会与任何物体产生物理碰撞，仅用于检测越界。

Code

关键代码讲解

四个核心脚本展示 Godot 4.x 的最佳实践：单例状态、数据驱动、AI 行为与碰撞架构。

scripts/game_manager.gd
GDScript 
## 全局游戏管理器（AutoLoad 单例）
## 职责：维护全局状态、分发跨系统信号、记录最高分
extends Node

# ── 信号 ──
signal score_changed(new_score: int)
signal health_changed(new_health: int)
signal game_over(final_score: int, rating: String)
signal wave_started(wave_number: int)

# ── 常量 ──
const MAX_HEALTH: int = 3
const RATING_THRESHOLDS: Dictionary = {
    "S": 10000,
    "A": 7000,
    "B": 4000,
    "C": 2000,
}

# ── 运行时状态 ──
var score: int = 0 : set = _set_score
var health: int = MAX_HEALTH : set = _set_health
var current_wave: int = 0
var high_score: int = 0


func _ready() -> void:
    ## 从本地配置文件读取最高分
    var config := ConfigFile.new()
    var err := config.load("user://save.cfg")
    if err == OK:
        high_score = config.get_value("game", "high_score", 0)


func start_game() -> void:
    ## 重置所有状态并开始新游戏
    score = 0
    health = MAX_HEALTH
    current_wave = 1
    get_tree().reload_current_scene()


func add_score(value: int) -> void:
    score += value


func take_damage(amount: int = 1) -> void:
    health -= amount
    if health <= 0:
        _trigger_game_over()


func calculate_rating() -> String:
    for rating in ["S", "A", "B", "C"]:
        if score >= RATING_THRESHOLDS[rating]:
            return rating
    return "D"


func _set_score(value: int) -> void:
    score = max(value, 0)
    score_changed.emit(score)


func _set_health(value: int) -> void:
    health = clamp(value, 0, MAX_HEALTH)
    health_changed.emit(health)


func _trigger_game_over() -> void:
    var rating := calculate_rating()
    if score > high_score:
        high_score = score
        _save_high_score()
    game_over.emit(score, rating)


func _save_high_score() -> void:
    var config := ConfigFile.new()
    config.set_value("game", "high_score", high_score)
    config.save("user://save.cfg")

设计要点：全局单例模式

GameManager 在 project.godot 中注册为 AutoLoad（自动加载），任何场景都可以通过 GameManager.score_changed.emit(...) 访问。使用 setter (: set = _set_score) 保证状态变更时自动发射信号，避免遗漏通知。

scripts/wave_manager.gd
GDScript 
## 波次管理器 —— 数据驱动配置 + 程序化生成
## 职责：根据波次数据生成敌人，控制游戏节奏
extends Node

signal wave_started(wave_number: int, total_enemies: int)
signal wave_cleared(wave_number: int)
signal enemy_spawned(enemy: Node2D)

# ── 导出配置 ──
@export var spawn_interval: float = 1.5  ## 同波内敌人生成间隔（秒）
@export var wave_interval: float = 3.0   ## 波次间隔（秒）

# ── 预加载敌人场景 ──
const ENEMY_BASIC := preload("res://scenes/enemy_basic.tscn")
const ENEMY_FAST  := preload("res://scenes/enemy_fast.tscn")
const ENEMY_TANK  := preload("res://scenes/enemy_tank.tscn")

# ── 波次配置表（数据驱动）──
var wave_data: Array[Dictionary] = [
    {"basic": 3, "fast": 0, "tank": 0},   # 波 1：热身
    {"basic": 5, "fast": 1, "tank": 0},   # 波 2：引入快速敌人
    {"basic": 4, "fast": 3, "tank": 0},   # 波 3
    {"basic": 3, "fast": 2, "tank": 1},   # 波 4：引入坦克
    {"basic": 5, "fast": 4, "tank": 1},   # 波 5
    {"basic": 4, "fast": 4, "tank": 2},   # 波 6
    {"basic": 6, "fast": 5, "tank": 2},   # 波 7
    {"basic": 5, "fast": 6, "tank": 3},   # 波 8
    {"basic": 8, "fast": 6, "tank": 3},   # 波 9
    {"basic": 6, "fast": 8, "tank": 4},   # 波 10：终局
]

var current_wave: int = 0
var _enemies_alive: int = 0
var _spawning: bool = false

@onready var _spawn_timer: Timer = $"SpawnTimer"
@onready var _wave_timer: Timer = $"WaveTimer"
@onready var _spawn_path: PathFollow2D = $"../EnemySpawnPath/SpawnLocation"
@onready var _enemy_container: Node2D = $"../EnemyContainer"


func _ready() -> void:
    _spawn_timer.timeout.connect(_on_spawn_timer_timeout)
    _wave_timer.timeout.connect(_on_wave_timer_timeout)


func start_first_wave() -> void:
    current_wave = 0
    _start_next_wave()


func _start_next_wave() -> void:
    if current_wave >= wave_data.size():
        return  ## 所有波次完成，进入胜利结算

    current_wave += 1
    var data := wave_data[current_wave - 1]
    var total := data["basic"] + data["fast"] + data["tank"]

    _enemies_alive = total
    _spawning = true

    ## 构建待生成队列
    _spawn_queue.clear()
    for i in range(data["basic"]): _spawn_queue.append(ENEMY_BASIC)
    for i in range(data["fast"]):  _spawn_queue.append(ENEMY_FAST)
    for i in range(data["tank"]):  _spawn_queue.append(ENEMY_TANK)
    _spawn_queue.shuffle()  ## 打乱生成顺序，避免模式化

    wave_started.emit(current_wave, total)
    _spawn_timer.start(spawn_interval)


var _spawn_queue: Array[PackedScene] = []


func _on_spawn_timer_timeout() -> void:
    if _spawn_queue.is_empty():
        _spawning = false
        _spawn_timer.stop()
        return

    var scene := _spawn_queue.pop_front()
    var enemy := scene.instantiate() as Node2D

    ## 在生成路径上随机位置生成
    _spawn_path.progress_ratio = randf()
    enemy.global_position = _spawn_path.global_position

    enemy.died.connect(_on_enemy_died)
    _enemy_container.add_child(enemy)
    enemy_spawned.emit(enemy)

    if not _spawn_queue.is_empty():
        _spawn_timer.start(spawn_interval)


func _on_enemy_died() -> void:
    _enemies_alive -= 1
    if _enemies_alive <= 0 and not _spawning:
        wave_cleared.emit(current_wave)
        _wave_timer.start(wave_interval)


func _on_wave_timer_timeout() -> void:
    _start_next_wave()

数据驱动的优势

波次配置是纯数据（Dictionary 数组），无需修改脚本逻辑即可调整难度曲线。未来可从 JSON / CSV 加载，甚至实现用户自定义关卡编辑器。

scripts/enemy_fast.gd
GDScript 
## 快速敌人 —— 黄色菱形
## 行为：高速下降 + 追踪玩家 X 轴，制造压迫感
extends "res://scripts/enemy_base.gd"

@export var speed: float = 180.0
@export var track_strength: float = 0.6  ## X轴追踪强度（0=不追踪, 1=完全锁定）

@onready var _player: Node2D = get_tree().get_first_node_in_group("player")


func _ready() -> void:
    super._ready()
    health = 2
    score_value = 20
    if _player == null:
        push_warning("FastEnemy: 未找到玩家节点，将执行直线下降")


func _physics_process(delta: float) -> void:
    var velocity := Vector2.DOWN * speed

    if _player != null:
        ## 计算朝向玩家 X 方向的水平偏移
        var diff_x := _player.global_position.x - global_position.x
        var track_x := sign(diff_x) * min(abs(diff_x), speed * track_strength)
        velocity.x = track_x

    move_and_collide(velocity * delta)

    ## 越界清理
    if global_position.y > get_viewport_rect().size.y + 50:
        queue_free()

AI 设计细节

track_strength 使用 min(abs(diff_x), speed * track_strength) 限制最大水平速度，避免敌人"瞬移"到玩家正上方。这种"有延迟的追踪"比直接锁定坐标更具可玩性。

scripts/player.gd
GDScript 
## 玩家控制 + HurtBox 碰撞架构
extends CharacterBody2D

signal died()

@export var move_speed: float = 300.0
@export var fire_rate: float = 0.15  ## 射击间隔（秒）
@export var invincible_time: float = 1.5

const BULLET_SCENE := preload("res://scenes/player_bullet.tscn")

var _can_fire: bool = true
var _is_invincible: bool = false

@onready var _muzzle: Marker2D = $"Muzzle"
@onready var _hurt_box: Area2D = $"HurtBox"
@onready var _sprite: Sprite2D = $"Sprite2D"
@onready var _invincible_timer: Timer = $"InvincibleTimer"
@onready var _fire_timer: Timer = Timer.new()


func _ready() -> void:
    add_to_group("player")

    ## 初始化射击计时器
    _fire_timer.one_shot = true
    _fire_timer.timeout.connect(_on_fire_timer_timeout)
    add_child(_fire_timer)

    ## HurtBox 碰撞信号连接
    _hurt_box.area_entered.connect(_on_hurt_box_entered)
    _invincible_timer.timeout.connect(_on_invincible_timeout)


func _physics_process(_delta: float) -> void:
    var input := Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
    velocity = input * move_speed
    move_and_slide()

    ## 限制在屏幕范围内
    var screen := get_viewport_rect().size
    global_position.x = clamp(global_position.x, 20, screen.x - 20)
    global_position.y = clamp(global_position.y, 20, screen.y - 20)

    ## 自动射击（按住空格或自动）
    if Input.is_action_pressed("ui_accept") or Input.is_action_pressed("shoot"):
        _try_fire()


func _try_fire() -> void:
    if not _can_fire:
        return
    _can_fire = false
    _fire_timer.start(fire_rate)

    var bullet := BULLET_SCENE.instantiate() as Area2D
    bullet.global_position = _muzzle.global_position
    get_tree().root.get_node("Main/BulletContainer").add_child(bullet)


func _on_hurt_box_entered(area: Area2D) -> void:
    if _is_invincible:
        return

    ## 通过 Area 的 collision_layer 判断伤害来源类型
    if area.get_collision_layer_value(4):  ## EnemyBullet
        area.get_parent().queue_free()  ## 销毁子弹

    _take_damage()


func _take_damage() -> void:
    GameManager.take_damage(1)
    _start_invincible()
    get_tree().root.get_node("Main/Camera2D").shake(0.3, 15)

    if GameManager.health <= 0:
        _die()


func _start_invincible() -> void:
    _is_invincible = true
    _hurt_box.set_deferred("monitoring", false)
    _invincible_timer.start(invincible_time)

    ## 无敌闪烁效果（通过 Tween 实现）
    var tween := create_tween()
    tween.tween_property(_sprite, "modulate:a", 0.3, 0.1)
    tween.tween_property(_sprite, "modulate:a", 1.0, 0.1)
    tween.set_loops(int(invincible_time / 0.2))


func _on_invincible_timeout() -> void:
    _is_invincible = false
    _hurt_box.set_deferred("monitoring", true)
    _sprite.modulate.a = 1.0


func _die() -> void:
    ## 实例化爆炸特效
    var explosion := preload("res://scenes/explosion.tscn").instantiate()
    explosion.global_position = global_position
    get_tree().root.get_node("Main").add_child(explosion)
    died.emit()
    queue_free()


func _on_fire_timer_timeout() -> void:
    _can_fire = true

HurtBox 架构说明

玩家身上只有 HurtBox（Area2D，检测受伤），没有 HitBox（因为子弹是独立场景）。敌人身上同时拥有 HitBox（造成伤害）和 HurtBox（接受伤害）。这种拆分让"谁打谁"的逻辑完全由碰撞矩阵决定，极大降低了耦合度。

Process

开发流程

按 7 个阶段循序渐进，每一阶段都有明确的交付物与验证标准，适合跟随教程复现。

Phase 1：项目搭建与输入系统

创建空项目，配置 project.godot：窗口分辨率 480×720（竖屏）、拉伸模式 canvas_items、输入映射（WASD + 空格）。建立文件夹结构 scenes/、scripts/、assets/。

  • 设置渲染 → 纹理滤镜为 Nearest（像素风兼容）
  • 输入映射：move_left/right/up/down、shoot
  • 版本控制初始化（Git + .gitignore 排除 .godot/）
Phase 2：玩家移动与射击

创建 player.tscn，使用 CharacterBody2D 作为根节点。实现 Input.get_vector() 移动、边界限制、按空格发射子弹。子弹使用 Area2D 向上飞行，越界自毁。

  • @onready 懒加载 Marker2D 作为发射口
  • 子弹容器统一挂在 Main/BulletContainer 下，避免场景树杂乱
  • 用 Timer 控制射击间隔，防止单帧连发
Phase 3：敌人基类与碰撞系统

设计 enemy_base.gd 抽象基类，定义 health、speed、score_value 与 died 信号。配置物理 Layer/Mask，建立 HurtBox/HitBox 双层碰撞架构。

  • 基类使用 class_name EnemyBase 注册全局类型
  • HurtBox（Layer=3, Mask=2）接受玩家子弹
  • HitBox（Layer=4, Mask=1）用于敌人子弹击中玩家
Phase 4：3 种敌人 AI 差异化

继承 EnemyBase 实现三种行为：基础敌人（正弦波 + 直线）、快速敌人（追踪 X 轴）、坦克敌人（慢速 + 3 连发散弹）。每种敌人使用独立的 .tscn 场景文件。

  • 基础敌人：sin(Time.get_time_dict_from_system().second) 做横向摆动
  • 快速敌人：通过 get_tree().get_first_node_in_group("player") 获取目标
  • 坦克敌人：每 2 秒发射 3 颗呈扇形分布的子弹，角度间隔 15°
Phase 5：波次管理系统

编写 wave_manager.gd，用 Dictionary 数组配置 10 波敌人数量。实现 Path2D + PathFollow2D 的随机生成位置，波次清空后自动进入下一波。

  • 打乱生成队列 _spawn_queue.shuffle()，避免固定模式
  • 信号：wave_started、wave_cleared 通知 UI 与粒子系统
  • 难度递增：敌人数量、生成间隔、种类混合度同步提升
Phase 6：UI 系统与状态机

构建三套 UI 场景：主菜单（开始/退出）、HUD（分数/生命/波次）、游戏结束（评级/重试）。使用 CanvasLayer 确保 UI 不受摄像机变换影响。

  • HUD 通过监听 GameManager.score_changed 自动更新
  • 游戏状态机：MENU → PLAYING → PAUSED → GAME_OVER
  • 评级算法根据最终分数映射 S/A/B/C/D 五档
Phase 7：特效与打磨

添加死亡爆炸粒子（GPUParticles2D）、摄像机震动（Camera2D.offset Tween）、玩家受伤无敌闪烁。调整手感参数（移速、射速、敌速），进行 30 分钟试玩测试。

  • 爆炸粒子：颜色从黄到红渐变，生命周期 0.4s，爆发 20 颗
  • 摄像机震动：随机偏移 Vector2(randf_range(-shake, shake), ...)
  • 无敌闪烁：Tween 循环修改 modulate:a，结束后恢复碰撞

扩展指南

基于本项目的代码结构，向更复杂的游戏演进的四个方向。

添加新敌人类型

① 新建 enemy_xxx.tscn，根节点继承 EnemyBase；② 在 wave_manager.gd 中 preload 新场景；③ 在 wave_data 的 Dictionary 中加入新键（如 "sniper"）；④ 实现 _physics_process() 定义独特移动/攻击逻辑。无需修改现有敌人代码。

添加道具 / 升级系统

① 创建 powerup.tscn（Area2D），掉落时进入 PowerUp 物理层；② 玩家 HurtBox 同时监听 Layer 6（道具）；③ 定义 PowerUpType 枚举：SHIELD、RAPID_FIRE、MISSILE；④ 在 player.gd 中处理拾取效果，用 Timer 控制持续时间。

添加 Boss 战

① 新建 boss.tscn，继承 EnemyBase 但使用 CharacterBody2D 获得更精确的移动控制；② 设计阶段转换：入场 → 攻击模式A → 血量 60% 转模式B → 血量 30% 狂暴；③ 使用 AnimationPlayer 控制入场动画与攻击前摇；④ 在 wave_data 第 10 波替换为单一 Boss。

导出到 Web / 移动端

Web：导出模板选择"Web"，注意单线程模式兼容性，禁用部分渲染特效（如复杂 Shader）。移动端：启用多点触控，用 TouchScreenButton 替换键盘输入，虚拟摇杆控制移动，右侧区域点击射击。调整 UI 锚点适配不同屏幕比例。

Standards

开发规范

本项目制定的编码规范，已写入每个代码文件的头部注释中。

GDScript 2.0 渐进式类型

关键变量显式标注类型（var speed: float = 100.0），提升性能和可读性。复杂函数标注返回类型（func _get_player() -> Node2D）。

@onready 懒加载

所有节点引用使用 @onready var sprite: Polygon2D = $Polygon2D，确保节点树就绪后才获取引用，避免 _ready 时序问题。

@export 暴露配置

可调整的参数使用 @export，如 @export var speed: float = 350.0，设计师可在 Inspector 中直接调整，无需修改代码。

信号命名规范

使用过去式命名信号：health_changed、enemy_died、wave_completed。信号作为节点间松耦合通信的核心机制。

命名规范

类名 PascalCase，变量/函数 snake_case，常量 UPPER_SNAKE_CASE，私有变量前缀 _（如 _is_invincible）。

中文注释

所有代码注释使用中文，方便国内团队阅读。每个文件头部有功能说明和责任描述。关键逻辑行旁有 inline 注释。

组合优于继承

功能拆分为独立场景组件，通过信号通信。如敌人由 Sprite + Collision + AIController 组合而成，而非单一巨型脚本。

全局状态单例

使用 AutoLoad 单例（GameManager）管理跨场景状态。避免节点间直接硬引用，所有通信通过信号或单例方法。

Extension

扩展指南

如何参考本项目，构建更复杂的游戏。

添加新敌人类型

  1. 新建场景继承 EnemyBase（或直接复制 enemy_basic.tscn）
  2. 修改 Polygon2D 颜色/形状，调整 CollisionShape2D 大小
  3. 新建脚本 extends EnemyBase，覆盖 _update_ai()
  4. 在 wave_manager.gd 的 ENEMY_SCENES 中注册新类型
  5. 在 WAVE_CONFIGS 中添加包含新敌人的波次

添加道具/升级系统

  1. 创建 PowerUp 场景（Area2D），如加速、护盾、散射
  2. 在 GameManager 中添加玩家属性（如 fire_level, shield_active）
  3. 敌人死亡时概率掉落道具：实例化 PowerUp 场景
  4. 玩家碰撞道具时：修改 GameManager 属性并更新 HUD

添加 Boss 战

  1. 创建 Boss 场景（继承 EnemyBase），大体积 + 多阶段
  2. 使用状态机管理阶段转换（Phase1 → Phase2 → Enrage）
  3. 每个阶段配置不同的 AI 行为、射击模式、移动轨迹
  4. 添加 Boss 专用血条 UI（TextureProgressBar）
  5. 在特定波次（如第 10 波）替换为 Boss 战

导出到 Web/移动端

  1. Web：在 Godot 编辑器中 项目 > 导出 > Web，需要安装 Web 导出模板
  2. Android：安装 Android SDK + JDK，配置调试密钥
  3. iOS：需要 macOS + Xcode 进行构建和签名
  4. 触控适配：添加虚拟摇杆和射击按钮（TouchScreenButton）
